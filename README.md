# Film 3.0

Первый рабочий каркас онлайн-версии Film на Next.js + Supabase.

## Уже готово

- Supabase Auth: регистрация / вход / выход
- автоматический профиль после регистрации
- Главная
- Обзор
- Закладки
- Профиль
- Друзья — заготовка
- адаптивный тёмный интерфейс
- подключение к существующей Supabase БД Film 3.0

## Запуск

1. Установить Node.js 20+.
2. Скопировать `.env.local.example` в `.env.local`.
3. Вставить Supabase Publishable Key.
4. Выполнить:

```bash
npm install
npm run dev
```

5. Открыть http://localhost:3000

## Важно

В браузере используется только Publishable key. Secret key сюда НЕ вставлять.

Следующий этап: TMDB API → поиск фильмов → карточка фильма → статусы → оценки → отзывы → коллекции → друзья → рекомендации.


## TMDB

В v3 добавлен серверный прокси к TMDB:
- `/api/tmdb/search` — поиск фильмов/сериалов/людей
- `/api/tmdb/movie/[id]` — подробности фильма
- `/api/tmdb/popular` — тренды недели

Нужен `TMDB_ACCESS_TOKEN`. Он хранится только на сервере и не попадает в браузер.
Получить его можно в TMDB Account Settings → API.


## Библиотека v3

Карточка фильма теперь умеет:
- создать/обновить запись фильма в `movies`;
- сохранить пользователя в `user_media`;
- менять статус: planned / watching / watched / on_hold / dropped;
- сохранять личную оценку 0–10;
- сохранять отзыв;
- добавлять в избранное.

Раздел «Закладки» загружает реальные данные текущего пользователя из Supabase и показывает количество по статусам и последние добавления.


## Социальный слой

Добавлены:
- общий рейтинг Film по сохранённым пользовательским оценкам;
- вывод отзывов пользователей на странице фильма;
- поиск публичных профилей;
- отправка заявок в друзья;
- профильные карточки пользователей.

Важно: принятие/отклонение входящих заявок и полноценная лента активности — следующий модуль.


## Социальный модуль 2

- входящие заявки;
- принятие/отклонение;
- список друзей;
- удаление друзей;
- реальные счётчики профиля;
- средняя оценка;
- активность пользователя.


## Коллекции

- создание коллекций прямо из карточки фильма;
- добавление фильма в коллекцию;
- список собственных коллекций в профиле;
- переключатель публичная/приватная;
- публичные коллекции пользователей отображаются в «Обзор».


## Публичные профили

Добавлено открытие профиля другого пользователя из списка друзей/поиска:
- статистика;
- публичные коллекции;
- последние фильмы;
- активность;
- количество друзей;
- средняя оценка.


## Главная v3

Добавлены:
- лента активности друзей;
- персональный блок «Для вас»;
- подбор по любимому жанру на основе оценок;
- график просмотров в профиле по месяцам/неделе.


## Discovery v3

Добавлены:
- 🎲 случайный фильм;
- 🗓 ближайшие релизы;
- 🌸 отдельная подборка аниме;
- 📱 нижняя мобильная навигация;
- API-роуты для discovery.


## Dedicated pages

Добавлены отдельные URL:
- `/movie/[tmdbId]` — полноценная страница фильма;
- `/collection/[id]` — полноценная страница коллекции.

Карточки discovery теперь ведут на страницы фильмов.


## Public profile URLs

Добавлен маршрут `/u/[username]`.
Пример: `/u/alex`.
Публичный профиль содержит статистику, публичные коллекции, последние фильмы и активность.


## Email confirmation

Регистрация использует Supabase PKCE callback:
`/auth/callback`.

После подтверждения письма Supabase возвращает пользователя на callback,
код обменивается на сессию, затем пользователь возвращается на `/`.
